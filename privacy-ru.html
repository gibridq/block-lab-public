Игровые данные

Приложение сохраняет на устройстве текущую партию, счёт, личные рекорды, пройденное обучение, выбранный язык и настройку звука. Эти сведения нужны для продолжения игры и сохранения настроек. Игровой код не отправляет сохранения на сервер издателя. Учётная запись, облачные рекорды, покупки и отдельная аналитика издателя отсутствуют.

Данные остаются в хранилище приложения до очистки данных или удаления игры. Новая партия заменяет текущую партию, но не удаляет рекорды и настройки. Полное удаление локальных сведений доступно через «Очистить данные» в системных настройках Android; оно также удалит ваш прогресс.

Добровольная реклама

После проигрыша игра предлагает необязательное продолжение за просмотр рекламы. Используется Yandex Mobile Ads SDK 8.5.0. Инициализация рекламного SDK запрашивается игровым кодом при выборе рекламного продолжения; во время обычной игры рекламные запросы игровым кодом не выполняются. При отказе от просмотра можно начать новую партию.

В этой версии код передаёт SDK отсутствие согласия на персонализацию и включает ограничения для младшего возраста, отключает отслеживание местоположения и отправку событий рекламной аналитики приложения. Это не означает полного отсутствия сетевой обработки рекламным сервисом. Доступ к геолокации, камере, микрофону, контактам и пользовательским файлам игра не запрашивает.

Для рекламы SDK может обрабатывать доступные идентификаторы устройства, включая рекламный идентификатор при наличии системного разрешения, и сетевые сведения, необходимые для доставки рекламы. SDK взаимодействует с сервисами Яндекса; условия их обработки описаны в политике Яндекса. По документации SDK сведения передаются с использованием HTTPS/TLS. Отдельно доступны сведения Яндекса о данных SDK.

Разрешения INTERNET и ACCESS_NETWORK_STATE нужны для загрузки рекламы и проверки подключения. Разрешение AD_ID добавляется зависимостью рекламного SDK. Ограничения рекламного идентификатора также доступны в системных настройках Android.

Обращения и внешние ссылки

Если вы пишете в поддержку, издатель получает сведения, которые вы сами включили в письмо, и использует их для ответа. Не отправляйте пароли или платёжные данные. Переход по внешней ссылке открывает сторонний ресурс с его собственными правилами обработки данных.

Чтобы уточнить обработку данных или направить запрос об удалении, обратитесь по указанному контакту поддержки. Запросы, относящиеся к данным сервисов Яндекса, также можно направить через их каналы поддержки. Издатель не обещает самостоятельно удалить сведения из систем третьей стороны.

Изменения

При изменении состава SDK или способов обработки данных политика обновляется с указанием даты. Игра рассчитана на общую аудиторию, включая детей. В SDK включён режим ограничения обработки данных для младшего возраста. Отдельный детский профиль и запрос даты рождения отсутствуют. Первый выпуск распространяется в России.
